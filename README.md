# I2ML-2026

Course website for Introduction to Machine Learning (CS 460200), Fall 2026, NTHU.

Built with Jekyll and the [Just the Class](https://github.com/kevinlin1/just-the-class) template on top of [Just the Docs](https://github.com/just-the-docs/just-the-docs). GitHub Pages builds it directly from the `main` branch; no local build is needed.

- Edit content in the `.md` files at the repo root and in `assignments/`.
- Add an announcement by creating a file in `_announcements/` with `title` and `date` front matter.
