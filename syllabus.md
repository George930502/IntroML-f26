## Course description

This course covers principles, algorithms, and applications of machine learning. The topics include formulation of learning problems, supervised learning, unsupervised learning, and model evaluation. Classical methods such as support vector machines, random forests, and neural networks will be introduced, followed by deep learning topics including convolutional networks, recurrent networks, Transformers, large language models, generative models, and reinforcement learning.

The goals of the course are

1. To understand the basic principles of machine learning.
2. To become familiar with widely used machine learning algorithms and use them to solve real problems.
3. To learn tools that allow you to apply machine learning algorithms to real data (and to debug the code generated by LLMs).
4. To properly evaluate model performance and tell what a "good" model is.

There will be little math or proof of theory. Upon successful completion of this course, students are expected to be familiar with widely used machine learning algorithms and be able to apply them to real data.

## Grading

Grades will be assigned based on

- 3 exams (35%): Midterm 1 (10/6), Midterm 2 (11/10), and Final Exam (12/15). Written exams, in classroom, closed-book. No electronic devices are permitted.
- 4 labs (40%): each lab is due 3 weeks after the announcement. Google Colab is recommended. A demo is required for each lab.
- Term project (25%): proposal, presentations, final report, and code. See [Project](project).
- Extra bonus (up to 5%): active engagement in class, such as answering questions on eeclass or identifying major errors in slides or labs, will be rewarded with additional points.

These weights are subject to minor variation.
